### Practical Overview

In this practical, a static website is deployed using **Azure Blob Storage**. The practical covers:

1. Preparing the Azure environment and resource group
2. Creating a Storage Account
3. Enabling Static Website Hosting
4. Creating `index.html`
5. Uploading website files to the `$web` container
6. Creating and testing a custom `404.html` page
7. Verifying the live website through the Primary Endpoint
8. Updating website content
9. Reviewing blob properties and access tier
10. Cleaning up the Azure resources
